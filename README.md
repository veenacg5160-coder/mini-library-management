---Mini Library Management System---

A simple Python-based library management system developed for the LF 2026 Mini Library Management System Challenge.

## Features

* Add and search books
* Borrow and return books
* Prevent borrowing unavailable books
* Track borrowers and due dates
* Detect overdue books
* Display library summary
* Maintain borrowing history
* Save data persistently using JSON
* Save borrowing records to a text file

## Technologies

* Python
* Lists and Dictionaries
* JSON File Handling
* Text File Handling
* `datetime` module

## Files

library.py
library_data.json
borrowing_records.txt
README.md
obstacle_log.txt

## How to Run

```bash
python library.py
```

The program provides a menu for managing books, borrowing, returning, records, and library statistics.
